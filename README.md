## 🚀 Installation

```bash
git clone <your-repository-url>
cd EmpireOS-AI

pip install -r requirements.txt

streamlit run app.py
```

---

## 🔑 Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=YOUR_API_KEY
```

Optional:

```env
APP_ACCESS_PASSWORD=YOUR_PASSWORD
```
